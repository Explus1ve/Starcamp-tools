# Starcamp Tools

Free tools built while building [Starcamp](https://starcamp.ai) — a place where people learn AI practice with the people who use it every day.

We keep running into jobs that should be simple and are not. When we solve one properly, we clean it up and put it here. No subscriptions, no dashboards, no accounts. Take what is useful.

## What is here

| Tool | What it does |
|---|---|
| [discord-tool-x-claude](discord-tool-x-claude/) | Stands up a fully configured Discord community server — roles, categories, channels, permissions, moderation, a rules gate and onboarding — in one run. Written to be driven by Claude, so you do the deciding and the clicking, not the coding. |

More on the way.

## How these are meant to be used

Every tool here is built to be run by a person who is not a developer, working with an AI assistant. Each one has a `START-HERE.md` that tells you exactly what to say to get going. If a tool cannot be used that way, it does not belong in this collection.

## A word on safety

Several of these talk to services on your behalf and need a token to do it. A token is a password. It goes in a local file that is never committed, never in a chat window, and never in a screenshot. Each tool says this again where it matters, because it matters.
